# Env sync (`make env` / `make env-check`) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** One command brings every member `.env` and deploy's `federation.env` in step with its example without changing a set value, and `make up` refuses to start while a `.env` is behind.

**Architecture:** A stdlib-only Python package `scripts/envsync/` behind a thin entry point `scripts/env_sync.py`. Per file: parse (compose dotenv or make syntax) → plan (keep / add / follow / rename / orphan) → shared-value pass across files → render from the example → self-checks → atomic write with backup. `make env` writes; `make env-check` runs the same pipeline read-only and gates `up`/`up-dev`.

**Tech Stack:** Python ≥ 3.9 standard library (`unittest`, `fcntl`, `secrets`, `argparse`, `dataclasses`), GNU make, GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-11-07-env-sync-design.md`

## Global Constraints

- Python ≥ 3.9, standard library only. Every module starts with `from __future__ import annotations`; no 3.10+ runtime syntax (`match`, `X | Y` outside annotations, `zip(strict=)`).
- Run with `python3 -B` (Makefile) and add `__pycache__/` to `.gitignore`: nothing may appear in the tree besides intended files.
- Never print or log an operator value. Fixtures write every operator secret as a string starting with `SENTINEL-`; tests assert it never appears in stdout, stderr, exception text, or any file other than the `.env` itself and files under the state directory.
- A value is printed only when it comes from an example and the key is not secret-like (`is_secret_like`).
- Nothing is ever created inside a member directory except its `.env`.
- Exit codes: 0 ok; 1 refused/missing file, shared conflict, or (check) behind / never synced; 2 usage error, table error, lock held, unusable state directory.
- Secret-like: `re.search(r"SECRET|PASSWORD|PASSPHRASE|TOKEN", key) or re.search(r"(^|_)KEY$", key)`.
- Held (never follows a default): secret-like, `"RETENTION" in key`, key in a shared group of that member, or any key of `federation.env` (make syntax).
- State directory `deploy/.env-sync/` (0700): `base/<file_id>.example` (0600), `backup/<file_id>/<YYYYmmddTHHMMSSZ>.env` (0600, last 5 kept), `lock`, `tmp/`.
- No `$(MAKE)` in the `env` / `env-check` recipes (`make -n` executes such lines).
- Fixtures are synthetic: invented keys, `*.example.invalid` hosts, no real data, no absolute local paths.
- deploy rules: work on branch `feat/env-sync`; small conventional commits; the version bump is its own `chore(release): v0.7.0` commit.
- Tests run from the repo root with `python3 -B -m unittest discover -s tests -p '<file>' -v` (one module) or `-p 'test_*.py'` (all). `tests/` is not a package; test modules import `envsync_helpers` directly.

## Review Focus

1. An operator `.env` saved with CRLF line ends or a byte-order mark: refused with its line number, untouched, and the other files still sync (tests in Task 1 and Task 7).
2. Values containing `=`, a `#` without a blank before it, a URL fragment, or quotes: kept byte for byte and decoded exactly like compose (Task 1 decode table, Task 4 byte-identity).
3. An empty or missing `.env`: rebuilt from the example; a new file is 0600; the empty one is backed up first (Task 7).
4. A `.env` that is a symlink (to a shared secrets file): refused, the link target untouched (Task 6).
5. A member listed in `federation.env` whose directory is missing on this host: reported as missing, the others still sync, exit 1 (Task 7).

### Task 1: Parse `.env` files the way compose does

**Files:**
- Create: `scripts/envsync/__init__.py` (empty), `scripts/envsync/dotenv.py`
- Create: `tests/envsync_helpers.py`, `tests/test_envsync_dotenv.py`
- Modify: `.gitignore` (add `.env-sync/` and `__pycache__/`)

**Interfaces:**
- Produces (`envsync.dotenv`):
  - `KEY = r"[A-Za-z_][A-Za-z0-9_]*"`
  - `class ParseError(Exception)` with `.lineno: int`, `.reason: str`, `str(e) == f"line {lineno}: {reason}"` — reason never contains line content.
  - `@dataclass(frozen=True) class Line: lineno: int; raw: str; kind: str; key: Optional[str]; value: Optional[str]; exported: bool` — `kind` ∈ `"blank"`, `"comment"`, `"setting"`, `"commented"`.
  - `@dataclass class EnvFile: lines: List[Line]; syntax: str` with `settings() -> Dict[str, Line]` (active lines by key), `commented(key: str) -> List[Line]`, `decoded() -> Dict[str, str]` (active key → value).
  - `parse(text: str, syntax: str = "dotenv") -> EnvFile` (`syntax` ∈ `"dotenv"`, `"make"`)
  - `parse_line(raw: str, syntax: str = "dotenv") -> Line` (one line, lineno 1)
  - `decode(rest: str, syntax: str) -> str` — `rest` is the text after `=`; raises `ValueError` on an unterminated quote or text after a closing quote.
  - `uncomment(raw: str) -> str` — strips the leading `#` and at most one blank.
  - `references(line: Line) -> List[str]` — names in `${X}` / `$X` of the value text, `$$` skipped, first-seen order.
  - `rewrite_key(raw: str, old: str, new: str) -> str` — replaces only the key token.
  - `lint(env: EnvFile) -> List[Tuple[int, str]]`
  - `is_secret_like(key: str) -> bool`
- `tests/envsync_helpers.py` produces `ROOT`, puts `ROOT/"scripts"` on `sys.path`, and `assert_no_sentinel(tc, *texts)`; Task 7 extends it.

Line classification (dotenv): blank if `raw.strip() == ""`; if the first non-blank character is `#`: `commented` when `re.match(rf"^# ?({KEY})=(.*)$", raw)` (no blank before `#`, at most one after), else `comment`; otherwise `setting` when `re.match(rf"^\s*(export\s+)?({KEY})\s*=(.*)$", raw)`, else `ParseError("unsupported syntax")`. Make syntax: `setting` only for `rf"^({KEY})\s*=(.*)$"`; `export`, leading blanks, `+= ?= := ::= !=`, `define`, `ifeq`, `override` → `ParseError`. A commented line whose value does not decode gets `value = rest.strip()` (no error). Whole-file errors: text starting with `﻿` → `ParseError(1, "byte-order mark")`; a line containing `\r` → `"CRLF line end"`; a second active line for a key → `"duplicate key (first defined on line M)"`. A missing final newline is fine.

Decode (dotenv): strip leading blanks and tabs; `'...'` literal; `"..."` with `\\`, `\"`, `\n`, `\t` unescaped; after a closing quote only blanks or a blank-preceded `#...` may follow; unquoted → cut at the first `" #"` (blank then `#`), then strip trailing blanks/tabs. Decode (make): strip leading blanks; `\#` → `#`; an unescaped `#` ends the value; trailing blanks are **kept**.

Lint messages (exact): dotenv `rest` matching `^[ \t]*#` → `"empty value followed by a comment: compose reads the comment as the value; put the comment on its own line"`; unquoted dotenv value containing `\t#` → `"a tab before '#' does not start a comment; compose keeps it in the value"`; make setting with an unescaped `#` → `"inline comment in federation.env: make keeps the blanks before it in the value"`.

### Task 2: Example model — anchors and rename directives

**Files:**
- Create: `scripts/envsync/example.py`, `tests/test_envsync_example.py`

**Interfaces:**
- Consumes: `envsync.dotenv` (Task 1).
- Produces (`envsync.example`):
  - `class ExampleError(Exception)` (wraps `ParseError` text unchanged)
  - `@dataclass class Example: env: EnvFile; renames: Dict[str, str]` — `renames` maps every OLD to the **end** of its chain.
    - `active() -> Dict[str, Line]`, `documented() -> Set[str]` (active ∪ commented keys), `candidates(key) -> List[Line]` (commented lines, file order), `values(key) -> Set[str]` (decoded values of the key's active and commented lines), `raw_lines() -> Set[str]`, `anchor_for(key: str, line: Line) -> Optional[Line]`
  - `load_example(text: str, syntax: str = "dotenv") -> Example`
  - `is_prose(value: str) -> bool` — True if the value contains whitespace or ends with `.`, `,`, `;` or `:`.

Directives: a line matching `^#\s*renamed:` must match exactly `rf"^# renamed: ({KEY}) -> ({KEY})$"`, else `ExampleError("line N: malformed renamed directive")`. Validation errors (exact): `"renamed: OLD is still a key of the example"` (OLD in `documented()`), `"renamed: OLD appears twice"`, `"renamed: cycle through OLD"`, `"renamed: NEW is not a key of the example"` (end of chain not documented).

Anchor rules, first match wins: (1) the active line for `key`; (2) a candidate with `uncomment(c.raw).rstrip() == line.raw.rstrip()`; (3) a candidate with `c.value == line.value`; (4) the first candidate with `not is_prose(c.value)`; (5) the first candidate; else `None`.

### Task 3: Plan one file — keep, add, follow, rename, orphan

**Files:**
- Create: `scripts/envsync/plan.py`, `tests/test_envsync_plan.py`

**Interfaces:**
- Consumes: Tasks 1–2.
- Produces (`envsync.plan`):
  - `class PlanError(Exception)`
  - `@dataclass class Entry: key: str; raw: str; value: str; origin: str` — `origin` ∈ `kept added followed carried filled generated`
  - `@dataclass class Orphan: line: Line; comments: List[str]; note: Optional[str]`
  - `@dataclass class Event: kind: str; items: List[str]; level: str = "info"` — `items` are display-safe strings, built at creation.
  - `@dataclass class FilePlan: file_id: str; display: str; syntax: str; created: bool; entries: Dict[str, Entry]; unset: Dict[str, str]; orphans: List[Orphan]; events: List[Event]; dropped_comments: int; shared_keys: FrozenSet[str]; has_base: bool` with `effective() -> Dict[str, str]` (entries ∪ orphans, key → decoded value).
  - `is_held(key: str, syntax: str, shared_keys: FrozenSet[str]) -> bool`
  - `plan_file(file_id: str, display: str, example: Example, base: Optional[Example], env: Optional[EnvFile], shared_keys: FrozenSet[str] = frozenset()) -> FilePlan`
  - `placeholder_event(plan: FilePlan, example: Example, base: Optional[Example]) -> Optional[Event]` — `kind="placeholder"`, `level="warn"`, items = secret-like keys whose non-empty value is in `example.values(k)` or the base's values, or contains `<...>`; keys in `shared_keys` are excluded.

Algorithm (`ops` = `env.settings()`, `opc` = first commented line per key in `env`, `E`/`B` = example/base; `inherited(k)` = `B` has `k` active and `ops[k].raw.rstrip() == B.active()[k].raw.rstrip()`; `follows(k)` = `inherited(k) and not is_held(k, syntax, shared_keys)`):

0. `env is None` → `created=True`, entries = every example active line with origin `added`, no events.
1. Dotenv only: if an OLD of `E.renames` is in `ops` and another active line references it → `PlanError(f"line {n}: refers to a renamed key")`.
2. Renames, grouped by NEW over the OLDs in `ops`. An inherited OLD is dropped with `Event("renamed", [f"{old} -> {new} (old default dropped)"])`. Then with the live OLDs:
   - (a) more than one → each becomes an orphan with note `f"renamed to {new} together with another key; value not carried"`, `Event("rename_conflict", [...], "warn")`;
   - (b) `new in ops and not inherited(new)` → orphan, note `f"renamed to {new}; {new} is set and applies"`, `rename_conflict`;
   - (c) `B is None or old not in B.documented()` → orphan, note `f"renamed to {new} in the example; value not carried"`, `Event("rename_not_carried", [f"{old} -> {new}"], "warn")`;
   - (d) otherwise carry: `Entry(new, rewrite_key(ops[old].raw, old, new), ops[old].value, "carried")` and `Event("renamed", [f"{old} -> {new} (value carried)"])`.
3. Every other key in `ops`, in file order:
   - documented by `E`:
     - `follows(k)` and active in `E` → origin `followed` with the example line, plus `Event("followed", [f"{k}: {old} -> {new}"])`, unless the raw lines are equal, in which case `kept`;
     - `follows(k)` and only commented in `E` → no entry, `Event("unset_now", [k])`;
     - otherwise `kept`. If also held and inherited, and the example's active line changed since `B` → `Event("held", [f"{k}: {old} -> {new}"] if not secret-like else [k])`.
   - not documented: `follows(k)` → no entry, `Event("removed", [k])`; otherwise an orphan with no note and its attached comments, plus `Event("unknown", [k])`.
4. Each `E` active key without an entry:
   - `B` has it active → `unset[k] = opc[k].raw` if present, else `"# " + E.active()[k].raw`, plus `Event("kept_unset", [k])`;
   - `B is None` and `k in opc` → `unset[k] = opc[k].raw` plus `kept_unset`;
   - otherwise origin `added` with `Event("added", [f"{k}={value}"] if not secret-like else [k])`.
5. `B is None` → `Event("differs", [names of kept keys whose value != E's active value])` when non-empty.
6. Attached comments of an orphan: the contiguous `comment`/`commented` lines directly above it, stopping at a blank or a setting, skipping lines that start with `# [env-sync]` and lines in `E.raw_lines()`. `dropped_comments` = the env's comment and commented lines that are not markers, not in `E.raw_lines()`, not attached, and not used in `unset`; if > 0 → `Event("dropped_comments", [f"{n} comment lines not in the example dropped (see the backup)"])`.
7. `lint(env)` → `Event("lint", [f"line {n}: {msg}"], "warn")`.

Events for a key list items in file order; one event per kind.

### Task 4: Render from the example and self-check

**Files:**
- Create: `scripts/envsync/render.py`, `tests/test_envsync_render.py`

**Interfaces:**
- Consumes: Tasks 1–3.
- Produces (`envsync.render`):
  - `MARKER = "# [env-sync]"`

Group evaluation (rows whose member is not in `files` are skipped; a row whose key the member's example does not document → `Event("table", [f"env-sync.conf: {key} is not in {member}'s example"], "warn")`, skipped):
- **Placeholder set:** the union over the group's rows of `example.values(key)` and `base.values(key)`.
- **When a row counts as unset:** the row is unset when it has no entry, or its value is empty, starts with `#`, contains `<...>` (`re.search(r"<[^>]*>")`), or is in the placeholder set. A `source` row with an entry counts as set.
- **Entry rows:** split the list on `,`, then each item on the first `=` (both trimmed). The list counts as unset only when every item is empty or a placeholder. If the list is set, the row's value is the `entry` item's token; a set list without a real `entry` item is a conflict.
- **Conflict:** more than one distinct set value → `Event("conflict", [f"{key}: {member} differs from {other}"], "error")`; the group stays unchanged.
- **Fill:** exactly one set value `v` fills every unset row:
  - silent when the decoded value already equals `v`;
  - skipped with `Event("kept_unset", [key])` on that member's plan when the key is in `plan.unset`;
  - skipped with `Event("unsafe", [key], "warn")` on that member's plan when `v` does not match `SAFE_VALUE`;
  - otherwise `Entry(key, fill_line(existing, key, v), v, "filled")` (for an entry row the value is `f"{entry}={v}"`) and `Event("filled", [f"{key} (from {source_member})"])` on that member's plan.
- **Nothing set:** a `gen` group with `generate` → one `token()` per group fills all rows (origin `generated`, `Event("generated", [key])` on each plan). Otherwise a `gen` group returns `Event("unset_everywhere", [f"{key} ({members})"], "warn")`.

`fill_line`: `f"{'export ' if existing and existing.exported else ''}{key}={value}"`, then `" " + comment` when the existing line carried one. The comment is the text from the first `#` after a blank in the unquoted value, or the whole decoded value when that starts with `#` (the trap).

### Task 6: State directory, backups and atomic writes

**Files:**
- Create: `scripts/envsync/state.py`, `tests/test_envsync_state.py`

**Interfaces:**
- Produces (`envsync.state`):
  - `class StateError(Exception)`, `class LockHeld(Exception)`, `class WriteRefused(Exception)`
  - `BACKUPS_KEPT = 5`
  - `class StateDir(root: Path, create: bool)`:
    - `create=True` makes `root`, `base/`, `backup/` and `tmp/` with mode 0700 and resets wider modes to 0700;
    - `create=False` never creates anything;
    - a symlinked `root` → `StateError`.
    - Methods: `lock() -> ContextManager[None]` (`fcntl.flock(LOCK_EX | LOCK_NB)` on `root/"lock"`, raises `LockHeld`), `read_base(file_id) -> Optional[str]`, `write_base(file_id, text) -> None` (0600), `backup(file_id, data: bytes, now: Optional[datetime] = None) -> Path` (0600; a name collision gets `-1`, `-2`, ...; prunes to the newest `BACKUPS_KEPT`).
  - `@dataclass class Snapshot: path: Path; data: Optional[bytes]; stat: Optional[os.stat_result]`
  - `read_target(path: Path) -> Snapshot` — `WriteRefused` on a symlink, a hard link (`st_nlink > 1`) or a non-regular file; a missing file gives `data=None`.
  - `atomic_replace(snap: Snapshot, text: str, state: StateDir, file_id: str) -> None`
  - `world_readable(snap: Snapshot) -> bool`

`atomic_replace`, in order (each refusal raises `WriteRefused` with a reason and no content):
- Re-read the target; its bytes must equal `snap.data`, and a file that was missing must still be missing (`"changed while syncing"`).
- The owner must be `os.geteuid()` or the process must run as root (`"owned by another user"`).
- `state.root/"tmp"` must be on the target directory's `st_dev` (`"state directory on another filesystem"`).
- Write `tmp/<file_id>.<pid>.tmp` via `os.open(O_WRONLY | O_CREAT | O_EXCL, 0o600)` and fsync it.
- `chmod` it to the original mode (0600 for a new file); `chown` it to the original owner when running as root.
- `os.replace` it onto the target, then re-read and compare content and mode.
- On any failure the temp file is removed.

**Interfaces:**

    - `@dataclass class Target: dir: Path; file_id: str; display: str; syntax: str; env_path: Path; example_path: Path`
    - `target_for(dir_arg: str) -> Target`:
      - a dir with `federation.env.example` → `syntax="make"`, env `federation.env`;
      - otherwise `.env` / `.env.example`.

      In both cases `file_id` is the resolved directory's name and `display` is `f"{file_id}/{env file name}"`.
    - `main(argv: List[str]) -> int`
  - `envsync.report`:
    - `@dataclass class FileResult: display: str; status: str; plan: Optional[FilePlan] = None; backup: Optional[str] = None; error: Optional[str] = None; behind: bool = False; never_synced: bool = False`
    - `format_report(results: List[FileResult], shared: List[Event], check: bool) -> str`
  - Helpers for tests:
    - `make_member(infra, name, example, env=None, mode=0o600) -> Path`
    - `make_deploy(infra, example, env=None) -> Path`
    - `run_sync(*args, state, table) -> subprocess.CompletedProcess` (runs `[sys.executable, "-B", ROOT/"scripts/env_sync.py", "--state", state, "--table", table, *args]`, text, captured)
    - `tree_digest(root) -> Dict[str, str]` (relative path → sha256, every file)

CLI: `env_sync.py [--check [--allow-drift]] [--generate] [--state DIR] [--table FILE] DIR...`.
- Defaults: `--state DEPLOY_ROOT/".env-sync"`, `--table DEPLOY_ROOT/"env-sync.conf"`.
- Duplicate dirs are deduplicated.
- Exit 2 for any of: no `DIR`; `--generate` with `--check`; `--allow-drift` without `--check`; a missing or invalid table; `LockHeld`; `StateError`.

`main` pipeline:
1. Load the table.
2. Open the state directory with `create = not check`. In write mode, hold `lock()` for the whole run.
3. Per target:
   - missing dir or example → status `missing`;
   - read the example and the base (an unreadable base → warn `"stored copy unreadable; treated as never synced"`, `base=None`);
   - `read_target`, `parse`, `plan_file` with `shared_keys_for(groups, file_id)`;
   - any `ExampleError`, `ParseError`, `WriteRefused` or `PlanError` → status `refused` with the reason.
4. `apply_shared` over the planned files.
5. Per planned file:
   - `render` and `verify` (`CheckError` → `refused`);
   - add `placeholder_event`, and an `Event("readable", [display], "warn")` when the file is world-readable;
   - `behind = env is None or env.decoded() != plan.effective()`;
   - `never_synced = env exists and base is None`.
6. Check mode writes nothing. Statuses: `in sync` / `would write` / `would create`.
7. Write mode:
   - rendered bytes equal to the original → `unchanged`;
   - otherwise back up (if the file existed), then `atomic_replace` → `written` or `created`;
   - then `write_base(file_id, example text)` for every file that was written, created or unchanged (never for a refused one).
8. Print the report and return the exit code:
   - write mode → 1 if any `refused`/`missing` or a shared `conflict`, else 0;
   - check mode fails if any of those, or any `behind`, or any `never_synced`; with `--allow-drift` print `"WARNING: ENV_ALLOW_DRIFT=1 — 'make up' continues although .env files are behind their examples."` and return 0.

Report format:
- **File header:** `f"== {display:<24} {status}"`, plus `f" (backup: {backup})"` with the backup path relative to the state directory's parent.
- **Event line:** `f"   {LABEL[kind]:<11}{', '.join(items)}{SUFFIX[kind]}"`.
- **Shared events:** printed under `f"== {'shared':<24}"` after the files.
- **Write-mode summary:** `f"summary: {w} written, {u} unchanged, {r} refused, {c} conflict(s)."`, plus `" Changes apply with the next 'make up'."` when anything was written.
- **Check-mode summary:** `f"summary: {w} would change, {s} in sync, {r} refused, {c} conflict(s). Run 'make env' to apply."`.
- **Short form:** when nothing is behind and there is no `warn` or `error` event, only `f"env: {n} files in sync"` (check) or `f"env: {n} files unchanged"` (write) is printed.
- **never_synced:** adds the line `"   never synced: run 'make env' once"`.

|---|---|---|
| added | added | — |
| filled / generated | filled / generated | — |
| followed | followed | — |
| unset_now | unset | ` (the example no longer sets it; the default applies)` |
| removed | removed | ` (gone from the example; your line was its old default)` |
| held | held | ` (example default changed; yours kept)` |
| renamed / rename_not_carried / rename_conflict | renamed | — / ` (value not carried; see the end of the file)` / ` (both set; the new name applies)` |
| unknown | unknown | ` (not in the example; kept at the end)` |
